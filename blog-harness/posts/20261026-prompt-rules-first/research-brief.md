# 리서치 브리프 — 내가 쓰는 프롬프트는 남들과 다르다 (규칙 먼저 정하는 프롬프트)

기준일: 2026년 10월 26일

## 1. 검색의도: 정보형 — 근거
"프롬프트 잘 쓰는 법", "프롬프트 작성법"을 검색하는 AI 초보 직장인은 결과가 들쭉날쭉한 이유와 바로 쓸 수 있는 작성 방법을 알고 싶어 한다. 구매·신청 의도는 약하고, 방법·예시를 찾는 정보형이다.

## 2. 키워드
- 핵심: 프롬프트 잘 쓰는 법
- 보조: 프롬프트 작성법, 프롬프트 규칙, 프롬프트 지침, AI 업무 활용, 챗GPT 맞춤형 지침, 시스템 프롬프트, 프롬프트 템플릿, AI 결과물 품질
- 검색량: 미확인 (검색량 도구 없음 — 수치 기재하지 않음)

## 3. 독자 질문 목록 (질문 | 의도)
| 질문 | 의도 |
|---|---|

## 4. 필수 포함 하위주제 / 차별 포인트
- 필수(상위 콘텐츠 공통): 역할·작업·맥락·형식 같은 구성요소, 구체적으로 쓰기, 예시 제공, 반복 개선
- 차별 포인트: 대부분의 글은 "무엇을 넣을지"(재료 목록)에서 끝난다. 이 글은 **요청보다 규칙을 먼저 고정하는 순서**와 **애매한 단어 금지·완료 기준·자체 점검**이라는 저자 고유 방식(PromptForge 원칙)을 보여 준다. 규칙을 맞춤형 지침에 저장해 재사용하는 운영 방법까지.

## 6. 아웃라인 제안
- H1 후보: ① 내가 쓰는 프롬프트는 남들과 다르다: 요청보다 규칙을 먼저 정하는 법 ② 프롬프트 잘 쓰는 법, 질문보다 규칙을 먼저 쓰는 이유
- H2:
  1. 같은 질문인데 AI 답이 매번 달라지는 이유는? — 정해 주지 않은 빈칸을 AI가 추측으로 채우기 때문 (근거 4)
  2. 프롬프트를 잘 쓰는 사람은 무엇이 다른가요? — 요청 전에 규칙을 먼저 고정 (근거 1, 3, 4)
  3. 규칙 먼저 프롬프트, 5가지 칸 (역할·목표·제약·출력 형식·완료 기준) — 표 (근거 1, 3, 4, 6)
  4. 애매한 말을 숫자와 행동으로 바꾸는 방법은? — Before/After 표 (근거 3, 6)
  5. 바로 쓰는 규칙 먼저 템플릿 — 복사용 틀
  6. 매번 규칙을 다시 써야 하나요? — 맞춤형 지침 저장 (근거 5)
