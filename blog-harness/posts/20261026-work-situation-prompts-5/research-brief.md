# 리서치 브리프: 업무 상황별 프롬프트 5선

## 1. 검색의도: 정보형(실행 지향) — 근거
"업무 프롬프트", "직장인 프롬프트 예시"를 찾는 사람은 개념보다 **지금 바로 붙여 넣을 문장**을 원한다. 상위 결과(위키독스 업무 표준화 장, 마이크로소프트 코파일럿 프롬프트 갤러리 한국어판, M365 데일리 프롬프트 시리즈)도 상황별 예시 목록 형태다.

## 2. 키워드
- 핵심: 업무 프롬프트
- 보조: 직장인 프롬프트 예시, 업무용 AI 프롬프트, 이메일 작성 프롬프트, 회의록 요약 프롬프트, 보고서 작성 프롬프트, 엑셀 데이터 분석 프롬프트, ChatGPT 업무 활용
- 검색량: 미확인 (검색량 도구 없음)

## 4. 필수 포함 하위주제 / 차별 포인트
- 필수: 상황별 프롬프트 예시(메일·회의·보고·데이터·아이디어), 좋은 프롬프트의 구성 요소, 보안 주의
- 차별: ① 다섯 상황 모두 **같은 뼈대(목표·맥락·자료·결과 형식)**로 짜서 독자가 스스로 변형 가능하게 ② 각 프롬프트에 "이 칸만 바꾸세요" 안내 ③ 결과가 별로일 때 쓰는 후속 질문 한 줄 ④ 넣으면 안 되는 정보 체크리스트
- 같은 날 발행 예정인 「규칙을 먼저 쓰는 프롬프트」 글과 겹치지 않게: 원리 설명은 짧게, 템플릿 중심

## 6. 아웃라인 제안
- H1 후보: ① 업무 프롬프트 5선, 메일·회의록·보고서까지 복사해서 쓰세요 ② 직장인 업무 프롬프트 예시 5가지, 상황별 템플릿 정리
- H2
  1. 업무 프롬프트는 어떻게 써야 결과가 좋아지나요? — 목표·맥락·자료·결과 형식 네 칸 [근거#1·2·3]
  2. 업무 메일을 쓸 때는 어떤 프롬프트가 좋나요? — 받는 사람·목적·톤·길이 [근거#1·2]
  3. 회의록은 어떻게 정리를 맡기나요? — 결정 사항·할 일·담당·기한 표 [근거#4·5]
  4. 보고서·기획서 초안은 어떻게 부탁하나요? — 읽는 사람·결론 먼저·목차 [근거#2·6]
  5. 엑셀·데이터 정리는 어떻게 묻나요? — 열 설명·원하는 결과·검산 [근거#2]
  6. 아이디어가 막힐 때는 어떤 프롬프트를 쓰나요? — 개수·기준·평가표 [근거#2]
  7. 회사 업무에 AI를 쓸 때 무엇을 조심해야 하나요? — 민감 정보 [근거#7]
- FAQ: 다른 AI에서도 통하나 / 결과가 별로면 / 매번 입력해야 하나 / 영어로 써야 하나
